Guide d'installation

Pour Windows :

  1. Téléchargez le fichier d'installation en cliquant sur le bouton "Télécharger pour Windows"
  2. Ouvrez le fichier téléchargé (AnyDesk_Custom_Client.exe)
  3. Si une alerte de sécurité apparaît, cliquez sur "Exécuter"
  4. Le programme s'ouvrira automatiquement sans installation
  5. Communiquez-nous votre identifiant AnyDesk (affiché à l'écran) lorsque nous vous contactons

Pour Mac :

  1. Téléchargez le fichier d'installation en cliquant sur le bouton "Télécharger pour Mac"
  2. Ouvrez le fichier téléchargé (AnyDesk_Custom_Client.dmg)
  3. Faites glisser l'icône AnyDesk dans le dossier Applications
  4. Ouvrez AnyDesk depuis le dossier Applications
  5. Si un message de sécurité apparaît, allez dans Préférences Système > Sécurité et confidentialité et cliquez sur "Ouvrir quand même"
  6. Communiquez-nous votre identifiant AnyDesk (affiché à l'écran) lorsque nous vous contactons
